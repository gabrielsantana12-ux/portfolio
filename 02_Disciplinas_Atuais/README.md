# Projetos Acadêmicos e Disciplinas

Este diretório contém os projetos acadêmicos, códigos e resumos das 6 disciplinas do 1º Semestre de ADS:

* **Bootcamp I:** Planejamento da arquitetura do Study Hub e entregas do projeto de identidade profissional.
* **Introdução à Computação:** Anotações sobre fundamentos de hardware, software e funcionamento dos sistemas operacionais.
* **Matemática para Computação:** Exercícios de lógica matemática, álgebra booleana e teoria dos conjuntos.
* **Lógica de Programação e Algoritmos:** Exercícios práticos, algoritmos e fundamentos de raciocínio lógico.
* **Engenharia de Software:** Diagramas de casos de uso, requisitos e metodologias para modelagem de sistemas.
* **Banco de Dados I (Relacional):** Scripts SQL, modelos E-R e manipulação de dados estruturados.
