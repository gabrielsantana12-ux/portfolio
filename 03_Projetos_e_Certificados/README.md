# Projetos Pessoais e Certificações

Este diretório é reservado para o armazenamento de projetos práticos extracurriculares e certificados obtidos ao longo da minha jornada acadêmica e profissional em TI.

* **Certificações:** Comprovantes de conclusão de cursos extracurriculares e trilhas de aprendizagem (como os cursos do CEUB TI Academy, GitHub Foundations e NVIDIA).
* **Portfólio de Projetos:** Códigos e desenvolvimentos práticos pessoais criados para consolidar as minhas habilidades como desenvolvedor.
